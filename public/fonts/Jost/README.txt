Jost Variable Font
==================

This download contains Jost as a variable font:

  Jost/Jost-VariableFont_wght.woff2

Single wght axis (100-900), upright only (no italic — DESIGN.md), subset to
latin + latin-ext.

Serving as Marose's Patisserie Sans (body, buttons, labels, UI).

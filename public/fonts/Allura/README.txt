Allura Regular
==============

This download contains Allura as a static font:

  Allura/Allura-Regular.woff2

Weight 400 only, subset to latin + latin-ext.

Serving as Marose's Dulce Script (one calligraphic accent word per
composition: "algo dulce", "hecho con amor").

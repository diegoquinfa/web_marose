Fraunces Variable Font
======================

This download contains Fraunces as variable fonts:

  Fraunces/Fraunces-VariableFont_opsz,wght.woff2
  Fraunces/Fraunces-Italic-VariableFont_opsz,wght.woff2

Both files carry the opsz + wght axes only (SOFT/WONK were pinned to their
defaults and dropped to control weight), subset to latin + latin-ext.

Serving as Marose's Velvet Serif (headlines, section titles, hero copy).
